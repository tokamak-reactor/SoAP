## 1. Общее описание (b2cdca.F)

- B2.5 — неструктурированная сетка: можно мешить ДО реальных стенок
  вакуумной камеры, локальное сгущение.
- nCv ячеек = nCi внутренних + nCg guard.
- **Первичные данные: координаты ВЕРШИН и ЦЕНТРОВ ЯЧЕЕК** (в structured
  были только вершины crx/cry!).
- Магнитное поле: vxFpsi/vxFfbz на вершинах; компоненты B в центрах
  ячеек выводятся из них.

## 2. Геометрия (b2cdcv.F, строки 25–476)

### 2.1 Cell-centered (строки 31–80)

| Переменная | Смысл |
|---|---|
| nCv, nCi, nCg | число ячеек всего / внутренних / guard |
| cvX, cvY | Cartesian X,Y координаты ЦЕНТРА ячейки (в файле!) |
| cvBb | B в центре: (0:2)=(x,y,z), (3)=\|B\|. **0 ≤ cvBb(,0:3)** — компоненты НЕОТРИЦАТЕЛЬНЫ; направление задаёт cvEb |
| cvVol | объём ячейки (в тороид. симметрии включает 2π·R) |
| cvSz | площадь ячейки ⊥ z |
| cvHz | длина ячейки в z-направлении в центре |
| cvOnedBsq | 1/B² в центре |
| cvBzb | Bz/B² − Bz/<B²> (для P-S/mdf потоков) |
| cvEb | единичный вектор B в системе (R,Z,toroidal), \|cvEb\|=1 |
| signmf | направление полоидального поля: +1 по часовой, −1 против |

### 2.2 Face-based (строки 81–150)

| Переменная | Смысл |
|---|---|
| nFc | число граней; каждая 2D ячейка — полигон с N>2 гранями; грань соединяет 2 внутренние ячейки или внутреннюю с guard; **НЕТ граней между guard** |
| fcS | полная площадь грани |
| fcQgam | cos(t), sin(t): угол между cell-connector и нормалью грани (полоид. плоскость) |
| fcQalf | cos(t), sin(t): угол между B и нормалью грани; если Bz<0 → sin(t) = −sin(t) |
| fcQbet | cos(t), sin(t): угол между cell-connector и B; если Bz<0 → cos(t) = −cos(t) |
| fcPbs | (fcBx/fcBb)·sx — parallel contact area |
| fcPbshz | то же с hz |
| fcHc | (1:nFc,1:2) — **расстояния от центров ячеек fcCv до центра грани** |
| fcHt | длина грани в полоидальной плоскости |
| fcHz | длина грани в z-направлении |
| fcBb | B на гранях (аналог cvBb) |
| fcEb | единичный вектор B на грани |

### 2.3 Vertex-based (строки 151–192)

| Переменная | Смысл |
|---|---|
| nVx | число вершин |
| vxX, vxY | координаты вершин (в файле!) |
| vxFpsi | потенциал для (bx,by) на вершине: bx=(dpsi/dy)/(2πR), by=−(dpsi/dx)/(2πR) |
| vxFfbz | field function для bz на вершине: bz=ffbz/(2πR) |
| vxEb, vxBb, vxHz, vxOnedBsq, vxBzb | аналоги cv-величин на вершинах |

### 2.4 Flux-tube / flux-surface (строки 193–232)

| Переменная | Смысл |
|---|---|
| cvConn, vxConn, ftConn, fsConn | connection length (для ячеек/вершин/трубок/поверхностей) |
| ftEps | обратный аспект трубки |
| ftBbav2 | средний \|B\|² на трубке |
| fsPsi | **Psi на каждой флакс-поверхности** (для psi-нормировки!) |
| psi_increasing | направление роста Psi: от O-точки к активной X-точке |

### 2.5 Mapping (строки 233–476)

- cvFcP/cvFc — грани ячейки (pointer+list); cvFcP(iCv,1)=индекс начала, (iCv,2)=число
- fcCv (1:nFc,1:2) — 2 ячейки грани
- fcVx (1:nFc,1:2) — 2 вершины грани
- cvVxP/cvVx — вершины ячейки
- vxFcP/vxFc — грани, связанные с вершиной
- vxCvP/vxCv — ячейки, связанные с вершиной
- ftCvP/ftCv — ячейки флакс-трубки; ftFcP/ftFc — **грани ВНУТРИ трубки** (не флакс-выровненные); cvFt — трубка ячейки
- fsFcP/fsFc — грани флакс-поверхности; fcFs — поверхность грани
- fcReg, cvReg, ftReg — номера регионов
- fcAligned — выровнена ли грань с B
- cvOnClosedSurface — ячейка на замкнутой флакс-поверхности
- bcCvP/bcCv, bcFcP/bcFc, bcFcOr — граничные условия: guard-ячейки/грани по BC; bcFcOr = ±1 (внешняя нормаль совпадает с нормалью грани)
- rcCvP/rcCv, rcFcP/rcFc, rcFcOr — страты EIRENE (аналогично BC)
- fsVxP/fsVx, VxFs — вершины на флакс-поверхностях
- **isClassicalGrid** — сетка производна от structured: тогда nx/ny/nncut + imapCv/imapFcX/imapFcY/imapVx (обратная проекция iCv/iFc/iVx на (ix,iy) исходной structured)
- fcLbl, ftLbl, cvLbl — метки граней/трубок/ячеек
- /b2cmgs/ — сингулярные регионы (nlloc: 0=cell centers (1:nCv), 1=x-faces, 2=y-faces, 3=corners)

## 3. Состояние плазмы (строки 502–597) — ключевое отличие от STR

- na, ua, te, ti, po — (1:nCv) — на ЯЧЕЙКАХ.
- **fna, fna_mdf, fna_fcor, fhe, fhi, fch — (1:nFc, 0:1, ...) — на ГРАНЯХ!**
  (в structured были матрицы на ячейках со сдвигом: (-1:nx,-1:ny,0:1,0:ns-1))
- Знак потоков: положительны в сторону роста индекса (аналог str).

## 4. Residuals (строки 807–965) — те же, что в STR

resco/resmo (per species), resmb/resmt, reshe/reshi/resht, respo, коррекции
corpa/corua/..., нормы aresco/..., acorpa/... — идентично structured,
но размерности (1:nCv).

## 5. Выводы для SoAP

1. **Первичные данные unstr: cvX/cvY (центры) + vxX/vxY (вершины)**.
   fcX/fcY НЕТ — середины граней производные (mean 2 вершин).
   → центры ячеек ЧИТАТЬ из файла (b2ag считает их не mean(вершин),
   проверено: расхождение до 0.53 м).
2. **Потоки в unstr — на гранях (1:nFc)**. В str — на ячейках со сдвигом.
   Наша 1D-схема (imap_fcx/imap_fcy для STR, прямые грани для UNSTR)
   приводит оба к граням — это правильно и единообразно.
3. **cvBb в unstr — уже неотрицательные компоненты** (направление в cvEb);
   в str bb — со знаком (проверить наш np.abs!).
4. **fsPsi** — psi на флакс-поверхностях: для psi_norm в unstr (в str —
   cv_fpsi/fc_fpsi на ячейках; есть ли fs-версия — проверить).
5. **fcHc** — расстояния от центров ячеек до грани (в файле для unstr;
   для str вычислять из hx/hy или вершин).
6. **fcHt** — длина грани (полоид.); для str — из hx/hy/углов.
7. **bcFcOr / rcFcOr** — ориентация внешних нормалей (±1) — аналог
   нашего fc_or для structured (read_geometry.m:804-815).
8. **isClassicalGrid + imap*** — объясняет, почему в unstr b2fgmtry есть
   imap-массивы: для сеток, производных от structured.
9. **cvConn/ftConn** — connection length (у нас ft_conn есть для unstr).
