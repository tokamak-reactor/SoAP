## 1. Общее описание (b2cdca.F)

- B2 решает систему уравнений переноса многовидовой плазмы в 2D-геометрии.
- Программы: b2ag (геометрия+магнитное поле), b2ah (таблица параметров),
  b2ai (начальное состояние), b2mn (основной расчёт), b2yp (постобработка).
- **Сетка**: 2D, криволинейная, топологически прямоугольная. Координаты
  называются 'x' и 'y'. Ячеек: nx+2 вдоль x, ny+2 вдоль y. Индексация
  (ix,iy) в (-1:nx, -1:ny); ВНУТРЕННИЕ ячейки: (0:nx-1, 0:ny-1).
  Разрезы (cuts) — от X-точек.
- **Первичные данные сетки** — координаты 4 вершин всех ячеек: crx, cry.
  Метрические параметры (vol, hx, hy, qz, qc, gs) — ПРОИЗВОДНЫЕ от crx/cry.
- **Первичные данные магнитного поля** — flux functions fpsi и ffbz
  НА ВЕРШИНАХ ячеек; компоненты B в центрах ячеек выводятся из них.

## 2. Геометрия (b2cdcv.F, строки 25–245)

### 2.1 Углы ячеек и потоковые функции (первичные)

| Переменная | Размерность | Смысл |
|---|---|---|
| nx, ny | int | число внутренних ячеек по x и y; всего (nx+2)·(ny+2) |
| crx, cry | (-1:nx,-1:ny, 0:3) | координаты 4 углов ячейки в физической плоскости: 0=левый-нижний, 1=правый-нижний, 2=левый-верхний, 3=правый-верхний. Вдали от границ: crx(ix,iy,0)=crx(ix-1,iy,1)=crx(ix,iy-1,2)=... (могут не выполняться у разрезов) |
| fpsi | (-1:nx,-1:ny, 0:3) | потенциал для (bx,by) НА ВЕРШИНАХ: тороид. симметрия: bx=(dpsi/dy)/(2πR), by=−(dpsi/dx)/(2πR) |
| ffbz | (-1:nx,-1:ny, 0:3) | field function для bz на вершинах: bz=ffbz/(2πR) |

### 2.2 Магнитное поле

| Переменная | Смысл |
|---|---|
| bb | (-1:nx,-1:ny,0:3) — B В ЦЕНТРЕ ячейки: 0:2=(x,y,z)-компоненты, 3=|B|. bb(,,3)=sqrt(bx²+by²+bz²) |
| wbbl | B на середине ЛЕВОЙ грани |
| wbbr | B на середине ПРАВОЙ грани |
| wbbv | B на середине НИЖНЕЙ грани |
| wbbc | B на УГЛАХ (left-bottom corner), (-1:nx+1,-1:ny+1) |

### 2.3 Метрика (производная от crx/cry)

| Переменная | Смысл |
|---|---|
| vol | объём ячейки; в тороид. симметрии включает 2π·crx, в цилиндр. — 2π·cry |
| hx, hy, hz | x-, y-, z-диаметры ячейки. redef_gmtry=1: hz·bb(,,2)=sum(ffbz)/4 |
| qz | (,,0)=sin(t), (,,1)=cos(t); t — доп. угол между x- и y-направлениями (неортогональность) |
| qc | cos(t); t — угол между x-направлением ячейки и её левой гранью |
| gs | gsx=gs(,,0) — площадь грани с ЛЕВЫМ соседом; gsy=gs(,,1) — с НИЖНИМ; gsz=gs(,,2) — площадь ячейки ⊥ 3-й координате |
| hy1 | hy·qc — фактическое радиальное расстояние между соседними флакс-поверхностями; vol = hx·hy1·hz |
| hxb, hyl | x-диаметр нижней грани, y-диаметр левой грани |
| hzb, hzl, hzc | длины вдоль тор. направления: нижней грани, левой грани, вершин. hzl·hyl=gs(,,0); hzb·hxb=gs(,,1) |
| isymm | тип симметрии: 0=slab; 1,2=вращ. вокруг crx=0; 3,4=вокруг cry=0; 1,3=тороид.; 2,4=цилиндр. |
| periodic_bc | замыкается ли геометрия на себя (0/1) |
| /b2cmgs/ | сингулярные регионы: nlreg, nlxlo/nlxhi/nlylo/nlyhi (границы), nlloc (0=центры ячеек, 1=x-грани, 2=y-грани, 3=углы) |

### 2.4 Вспомогательные (auxiliary)

| Переменная | Смысл |
|---|---|
| pbs | pbsx=pbs(,,0)=(bx/bb)·sx, pbsy=pbs(,,1)=(by/bb)·sy — «parallel contact area» на левой/нижней гранях |
| pbshz | pbshzx/pbshzy = hz·(bx/bb)·sx, hz·(by/bb)·sy |
| bzb | Bz/B² − Bz/<B²> на центре ячейки |
| OnedBsq | 1/bb(,,3)² на центре ячейки |

## 3. Физические параметры и состояние плазмы (строки 246–388)

- /b2cmpa/: me, mp, ev, qe, eps0, mu0; nsdecl — верхняя граница ns.
- zamin, zamax, zn, am (0:ns-1): диапазон зарядов, ядерный заряд, атомная
  масса. Нейтральные не смешиваются с заряженными.
- ns — число сортов.
- na, ua, te, ti, po — плотность, параллельная скорость, Te, Ti, потенциал
  НА ЯЧЕЙКАХ. Знак ua: + = вдоль локального полоидального B.
- **Знак потоков**: потоки между полоидальными соседями +, если направлены
  в сторону УВЕЛИЧЕНИЯ индекса ix; радиальные — в сторону увеличения iy.

### Потоки (все: (-1:nx,-1:ny,0:1[,0:ns-1]), dim 0=x(полоидальный), 1=y(радиальный))

| Переменная | Смысл |
|---|---|
| fna | поток частиц сорта через грань с ЛЕВЫМ (fnax, dim0) / НИЖНИМ (fnay, dim1) соседом; ix=-1→fnax=0, iy=-1→fnay=0 |
| fna_mdf | модифицированный поток (== fna без дрейфов) |
| fna_fcor | поток для momentum transport (учёт hz и силы Кориолиса) |
| fhe, fhe_mdf | электронный тепловой поток (+ модиф.) |
| fhi, fhi_mdf | ионный тепловой поток (+ модиф.) |
| fch | электрический ток |

**Вывод**: «фейсовые» величины (потоки) в structured — это матрицы на
ячейках со сдвигом: fnax(ix,iy) живёт на грани между (ix,iy) и (ix-1,iy),
т.е. индекс ix сдвинут относительно «своей» ячейки. Подтверждает подход
Flux_flag из Matlab_SPb (сдвиг пределов по матрице).

## 6. Выводы для SoAP (что проверять / менять)

1. **x = полоидальное, y = радиальное** направление. hx — полоидальный
   размер, hy — радиальный. y2 (радиальная координата от сепаратрисы) =
   накопление hy; x2 (полоидальная) = накопление hx. Подтверждает карту
   geometry-structured-map.md.
2. **fpsi/ffbz — на вершинах (0:3)**. Наш cv_fpsi (nCv) — надо проверить,
   как мы усредняем вершины (b2fgmtry хранит 13600 = 3400·4 значений).
3. **bb(,,3) уже |B|** — наш np.abs(bb) избыточен, но безвреден.
4. **vol включает 2π·R** (тороид. симметрия) — при интегралах это уже
   учтено в vol; не умножать дополнительно.
5. **hy1 = hy·qc**; vol = hx·hy1·hz. Полезно для верификации чтения
   (если vol/hx/hy/hz/qz прочитаны верно, тождество выполняется).
6. **gsx/gsy** — площади граней (левая/нижняя). Сопоставить с нашей fc_s
   для structured (проверить, что fc_s = gs-интерполяция, а не что-то ещё).
7. **Сдвиг потоков**: fnax на грани (ix,iy)-(ix-1,iy). В 1D-представлении
   (st_us_transform_fc) это и есть imap_fcx/imap_fcy. Для профилей потоков
   на STR использовать сдвиг пределов (Flux_flag), координата y2 не меняется.
8. **Сингулярные регионы** (/b2cmgs/, nlreg/nlloc) — не читаем; для
   таргетов/сепаратрис используется топология разрезов (leftcut/...).
9. **zamin/zamax/zn/am** — уже читаем (b2fstati). Подтверждено: нейтралы
   не смешиваются с заряженными сортами.
10. **resco/resmo** (per species) — для полных метаданных workspace.
